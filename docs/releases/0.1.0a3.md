# OmindOS Locomotion 0.1.0a3

双足仿真模块的独立发布版本。源程序与开发在 [OmindOS-Locomotion](https://github.com/maganrobotics-boop/OmindOS-Locomotion)，安装包在 [OmindOS-Locomotion-Release](https://github.com/maganrobotics-boop/OmindOS-Locomotion-Release/releases)。

本版补齐中文安装、运行和故障排查步骤，并将源码仓与发布仓分开。保留现有 23 关节 Roboto Origin 模型适配、ONNX 策略、MuJoCo 仿真和可选 ROS 2 接口；运动控制算法及固定上游资产不变。

## 第一次使用

从本页附件下载 `.whl`、`requirements-sim.txt`、`USAGE.zh-CN.md` 和 `SHA256SUMS.txt`。在下载目录打开终端，使用 Python 3.12：

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-sim.txt
python -m pip install './omindos_legged_robot-0.1.0a3-py3-none-any.whl[sim]'
legged-robot fetch-assets --asset-dir assets/roboto-origin
legged-robot simulate --asset-dir assets/roboto-origin \
  --scenario baseline --duration 20 --output outputs/baseline
```

成功时输出 `completed`；日志在 `outputs/baseline/summary.json` 和 `simulation.csv`。首次显式下载约 34.1 MB 上游资产并校验 SHA256；普通仿真不要求 GPU 或 ROS 2。加 `--video` 生成 MP4，需 EGL/Mesa 与 ffmpeg，完整步骤见附件 `USAGE.zh-CN.md`。

## 附件和验证

- `.whl` 是安装包；`-source.zip` 是完整程序源码快照；`.tar.gz` 是标准 Python 源码发行包。
- `requirements-sim.txt` 固定已验收的 Python 3.12 仿真依赖；`USAGE.zh-CN.md` 解释环境、速度参数、视频、ROS 2、源码开发和故障排查。
- `SHA256SUMS.txt` 校验所有上述附件。
- 发布前执行全部 66 项测试和 20 秒平地基准（1,000 个控制步），并检查安装包及源码包。发布工作流会再次执行测试、基准及干净 wheel 安装检查。
- 对应源程序提交由发布仓库的 `release-source.json` 固定，构建后的版本和提交信息附在本页。

GitHub 自动生成的 `Source code` 是发布仓库自身的归档。要下载机器人程序源码，请选附件 `legged-robot-0.1.0a3-source.zip`，其中包含源码、测试、文档、GPL 文本和第三方通知。

这是**仿真预发布**。原生 ROS 2 图、Nav2、实机、Isaac Lab 训练和复杂地形仍未完成验收。默认前向指令范围为 -0.4～0.6 m/s，不是最高实测速度。发布不改写 [线上回放](https://cloud.omindos.cn/legged-robot/) 的历史运行版本。
